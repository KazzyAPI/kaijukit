# kaijukit

Open-source alternative to Atlassian's work-management products (issues, workflows, query language, permissions, REST API, docs/wiki).
Built in Rust (Axum, sqlx, Postgres) with a React/TypeScript web UI. Core logic compiles native and to WASM.

**Status:** specs only. No code yet. See [docs/parity/target.md](docs/parity/target.md) and [AGENTS.md](AGENTS.md).
