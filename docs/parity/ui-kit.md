# kaijukit UI kit parity (`@kaijukit/ui`)

Last reviewed: 2026-11-24 · decision: [ADR 0002](../decisions/0002-own-stack.md)

Goal: every component class in the reference design system's public documentation has an equivalent in `@kaijukit/ui` with the same role, states, keyboard/a11y behavior and comparable props. Styling is ours.
Status: `not started` | `partial` | `done` (needs a Storybook story, a11y test and a behavior test).
